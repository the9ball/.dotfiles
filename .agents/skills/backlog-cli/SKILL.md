# Backlog CLI

`$HOME/tools/Backlog.Cli/backlog.exe` は、Backlog のプロジェクト・ドキュメント・Wiki を検索・取得できる読み取り専用 CLI です。

詳細な使い方、接続設定、コマンド一覧、出力形式は、exe と同じフォルダの `README.md` を参照してください。

AI エージェントから使う場合は `--json` を優先してください。

API キーはプロンプト、ログ、最終回答に含めないこと。

## 実行方法

生の JSON をメインの会話コンテキストに残さないことが目的です。README とコマンド出力は委譲先に閉じ、必要な情報だけを要約で受け取ります。

Claude Code から使う場合:

- この CLI の実行は、安価なモデル(Haiku など)の読み取り専用サブエージェントに委譲するのを既定とする。
- 追加の照会は新しいサブエージェントを作らず、同じサブエージェントに続けて質問する(`SendMessage`)。README とコマンド出力がそのコンテキストに残るため、再取得が要らない。
- ドキュメントや Wiki の本文を逐語で使う必要があるときは「該当部分は逐語で返す」と明示するか、JSON をスクラッチパッドにファイル出力させて必要箇所だけ読む。

Codex app から使う場合:

- 読み取り専用の委譲先タスクが使えるなら委譲する。この CLI の実行は API 仲介とフィールド抽出だけなので、モデルと reasoning effort は利用可能な最小構成を選ぶ(`AGENTS.md` の低コスト優先方針に従う)。
- `$delegate-luna-investigation` は深い調査用に model と reasoning effort を固定しているため、この CLI の照会のためだけに同スキルの Luna タスクを作らない。すでに同スキルで調査を委譲していて、その一部としてこの CLI を使う場合は同スキルの判断に従う。
- 委譲先が使えない、または委譲のオーバーヘッドが作業を上回る場合はプライマリタスクで直接実行する。
