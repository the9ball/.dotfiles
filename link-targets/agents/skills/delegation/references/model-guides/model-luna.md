# Luna caller-side delegation guide

Caller-side reference for adapting a handoff or assessing results from an already selected delegate. It does not select models or reasoning effort, define child policy, or change governing contracts.

## Source metadata

- Official source: <https://developers.openai.com/api/docs/models/gpt-6-luna>
- Retrieved: 2026-10-08
- Covered model: `gpt-6-luna`.
- Official positioning: focused, high-volume tasks.
- Supported API reasoning effort: `none`, `low`, `medium` (default), `high`, `xhigh`, and `max`.

Revalidate the source before changing this reference. API support does not replace host settings or external selections; the composition map does not assume Luna will continue in another family.

## Caller adjustments

- Frame the assigned work as a focused deliverable with the relevant inputs and a directly checkable result, matching Luna's documented positioning.
- If representative results miss the task's quality bar, report the observed limitation through the existing delegation contract. Do not infer that a different reasoning effort or model is authorized.
